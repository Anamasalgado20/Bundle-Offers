¿por qué el mismo 10% para los 3 tests?

El descuento se mantiene fijo en 10% para los tres brazos de bundle por razón experimental: si se varía el descuento entre tests, se confunden dos variables al mismo tiempo (tipo de SKU y nivel de descuento), haciendo imposible aislar qué generó el resultado.

Con 10% fijo, la única variable que cambia es la composición del SKU secundario — que es exactamente lo que se quiere aprender.

Si T3 (non-movers) underperforma, el aprendizaje es claro: el umbral de descuento para mover un non-mover es mayor a 10%. Eso es información valiosa para la fase 2 y para la conversación con marcas.
